# Saheli

A comprehensive AI-powered platform designed to assist and empower women through intelligent guidance, safety-focused tools, personalized support, and accessible digital resources.

---

## Overview

Saheli is an intelligent companion platform built to provide support, awareness, accessibility, and assistance through modern AI technologies. The project focuses on delivering a user-friendly experience with practical features that help users access guidance, information, and digital support in a seamless way.

The platform combines modern frontend technologies, scalable backend architecture, and AI-driven capabilities to create a responsive and impactful application.

# Installation

## Prerequisites

Make sure the following are installed:

* Node.js (v18 or higher)
* npm or yarn
* Git

---

## Clone the Repository

```bash
git clone https://github.com/donkena-saiteja/Saheli.git
```

```bash
cd Saheli
```

---

## Install Dependencies

Using npm:

```bash
npm install
```

Or using yarn:

```bash
yarn install
```

---

# Environment Variables

Create a `.env` file in the root directory.

Example:

```env
NEXT_PUBLIC_API_URL=your_api_url
OPENAI_API_KEY=your_openai_api_key
DATABASE_URL=your_database_url
JWT_SECRET=your_jwt_secret
```

---

# Running the Project

## Development Mode

```bash

yarn dev
```
